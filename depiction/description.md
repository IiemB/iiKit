**iiKit** is a set of small tweaks that clean up and improve iOS, all in one package. Turn each feature on or off in **Settings › iiKit**, then tap **Respring Now**.

## Home Screen
- Hide app and folder labels, plus the TestFlight, "recently updated" and offloaded-app dots.
- Disable the Today View widget page.

## Lock Screen
- Remove the Flashlight and Camera buttons.
- Disable the Today View and Camera swipes.
- Disable the press-and-hold wallpaper switcher.
- Stop the camera from getting ready when you touch the right edge.

## Appearance
- Transparent Dock.
- Transparent Home Bar everywhere. Swipe gestures still work.
- Pure black OLED keyboard in every app.

## Gestures
- Double-tap an empty part of the Home Screen or Lock Screen to lock your device.
- In the App Switcher, pull any app card down to close all apps.

## Phone
- Silent keypad: no tones when you dial.

## Control Center
- **Open URL** tile: a 1×1 tile that opens any link you set in Settings › iiKit, such as a website, `shortcuts://` or `prefs:`. Needs CCSupport.
